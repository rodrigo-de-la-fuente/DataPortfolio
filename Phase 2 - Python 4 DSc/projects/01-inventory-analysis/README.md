# Python Inventory Analysis

## Description

Small Python project developed as part of my Data Analytics learning roadmap. It simulates the analysis of a store inventory and generates information about products, stock levels, and inventory value.


## Objectives

- Display the product catalogue.
- Calculate the number of different products.
- Calculate the total inventory value.
- Detect products with low stock.
- Detect critical stock levels.
- Identify the most expensive product.
- Sort products by price.

## Technologies

- Python

## Python concepts applied

- Lists
- Dictionaries
- `for` loops
- `if` statements
- List comprehensions
- `any()`
- `max()`
- `sum()`
- `sorted()`
- `enumerate()`
- Lambda functions

## Example output

The program generates a report including:

- Product catalogue
- Inventory value
- Low-stock products
- Critical-stock alerts
- Most expensive product
- Products sorted by price

## Learning outcome

This project applies Python data structures and collection-processing techniques to a small business problem.
