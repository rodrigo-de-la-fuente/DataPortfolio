# Atajos de teclado de VSCode

## Objetivos

En este archivo se concretan los atajos de teclado más útiles a la hora de navegar por VSCode sin necesidad de usar el cursor

## Atajos (en MacOS)

- Paleta de comandos: `command`+`P`+`shift`
- Abrir archivo: `command`+`P`
- Búsqueda local de palabras: `command`+`F`
- Búsqueda local con reemplazo: `command`+`F`+`option`
- Búsqueda global de palabras: `command`+`F`+`shift`
- Mostrar/ocultar terminal: `control`+`^`
- Comentar líneas en código Python, markdown...: `command`+`/`
- Mover líneas arriba/abajo: `option`+`↑`/`↓`
- Navegar entre pestañas: `control`+`tab`
- Renombrado inteligente: seleccionar una palabra + `fn`+`F2`
